# DOMKING CYBER

## 🌐 About the Project

**DOMKING CYBER** is a simple, modern and responsive cyber services website designed to help customers easily view available services and contact the business online.

The website provides information about cyber services such as printing, photocopying, scanning, typing, KRA services and online applications.

---

## 🚀 Features

- 🏠 Home page
- 💻 Services page
- 📞 Contact page
- 📱 WhatsApp contact link
- 📘 Facebook link
- 📸 Instagram link
- 📧 Email contact link
- 🔍 Service details
- 📱 Mobile-friendly design
- ✨ Interactive JavaScript features
- 🔗 Easy navigation between pages
- 🌐 Can be hosted using GitHub Pages

---

## 🛠️ Services Offered

DOMKING CYBER offers:

1. Photocopying
2. Printing
3. Scanning
4. Typing
5. KRA Services
6. Online Applications
7. CV Writing
8. Lamination
9. Internet Services

Customers can click **View Details** to get more information about each service.
